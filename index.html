“We want multiple paths to complete our quests.”

It happens all the time. We want quests to be more interactive and player-driven, and that means multiple paths to the same goal. It's the right instinct, but it means thinking in parallel as we design.

This is a small web demo of Quest Paths. The real tool runs in Python and is much more robust: 7+ approaches, 75+ verbs, rules from more than a dozen shipped and 10+ AAA games, and a save, edit, and “build from scratch” system. I'm constantly adding to the full Python version to use on my game projects.

Try this tool for yourself. It takes about a minute.

  1. 01Pick a quest to design.
  2. 02Give each player a way past each obstacle. Click any dot on the map, or follow the questions.
  3. 03Get all three lines to the goal. Then every player can finish the quest.
