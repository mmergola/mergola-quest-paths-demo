# Quest Paths

An interactive demo of Quest Paths, a quest-design tool by Mario Mergola.

Build a quest backward from its goal and give every player approach
a way through each obstacle. The tool tracks gaps until all paths reach
the goal.

This is a small web slice. The full tool is a Python application and is
not published here.
